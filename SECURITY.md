# Security policy

Report security issues affecting the current default branch or the latest published release through [GitHub private vulnerability reporting](https://github.com/jatmn/JiStats/security/advisories/new).

Include the affected version or commit, the impact, and steps to reproduce with synthetic data. Remove API keys, OAuth tokens, account identifiers, local paths, and conversation content from any sample. Keep vulnerability details in the private report while a fix is being coordinated.
